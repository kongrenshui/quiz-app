# 刷题考试（分享版）

一个纯前端的刷题 / 考试应用，导入题库即可用。数据全部保存在你自己的设备上，不上传任何服务器。

## 功能

- **导入题库**：JSON、CSV、Excel(.xlsx/.xls)，或从链接导入
- **组卷考试**：按题型设置抽题数、每题分值、及格分、时长，自动判分
- **练习**：顺序 / 随机，答完即时批改，可指定起始题号、随时跳题
- **断点续练**：退出、关浏览器都不丢，回来停在原题
- **错题本**：答错自动收录，可重做、可移除
- **统计**：通过率、平均分、考试记录
- **离线可用**：装到主屏幕后断网也能刷

## 手机上安装

**Android（Chrome / Edge）**：打开后菜单 → 添加到主屏幕 / 安装应用
**iOS（Safari）**：底部分享 → 添加到主屏幕

## 题库格式

### JSON

```json
{
  "name": "题库名",
  "questions": [
    { "type": "单选", "stem": "题干", "options": ["选项A", "选项B"], "answer": "A", "explanation": "解析" },
    { "type": "多选", "stem": "题干", "options": ["A项", "B项", "C项"], "answer": "AB" },
    { "type": "判断", "stem": "题干", "answer": "A" },
    { "type": "填空", "stem": "题干____", "answer": "答案" }
  ]
}
```

### CSV / Excel

| 题型 | 题干 | 选项A | 选项B | 选项C | 选项D | 答案 | 解析 |
|---|---|---|---|---|---|---|---|
| 单选 | 1+1=? | 1 | 2 | 3 | 4 | B | 算术 |
| 多选 | 哪些是质数 | 2 | 3 | 4 | 5 | ABD | |
| 判断 | 地球是圆的 | | | | | A | |
| 填空 | 水的化学式 | | | | | H2O | |

判断题答案 `A`=对、`B`=错，选项可留空。

## 从链接导入

题库页有「从链接导入」，粘贴题库 JSON 的地址即可。
也可以直接给对方一条带参数的链接，打开后自动导入：

```
https://<你的站点>/?bank=<题库JSON的URL>
```

## 数据说明

所有题库、练习进度、错题、成绩都存在浏览器的 localStorage 里，换设备不会同步。
题库页有「导出全部数据 / 导入备份」，可手动迁移。
